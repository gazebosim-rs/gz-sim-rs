# Independent loaded magnetometers

M52 is in development. Its preparation and parent qualification do not establish
M52 execution, coverage, release or acceptance. See [the delivery contract](M52_DELIVERY.md).

The bounded change admits up to eight otherwise-supported loaded Rapier
magnetometers. Each owner keeps its original public identity, full WORLD-scoped
name, publication metadata, resolved endpoint, demand, acquisition clock, cached
sample and noise state. Eight is a local resource bound, not an upstream limit.
The family shares its existing callback pair; retiring the last owner removes
the family resources, while a healthy loaded reset restores the original set.

The existing measurement remains the constant WORLD magnetic field rotated by
the inverse actual sensor WORLD quaternion, in Tesla. Translation and velocity
add no field term. Torque can change the orientation and therefore the measured
components. Existing XYZ noise is applied after rotation, with unchanged seed,
public-ID derivation, precision and reset behavior. A disconnected owner takes
no sample or draw. No native/Rust RNG or individual-demand equivalence is claimed.

Existing live geometry and deterministic-mean checks retain their `1e-18` Tesla
bound, historical M17 component checks retain `1e-15`, and retained M23 bit and
statistical assertions remain separate. Canonical Header, Vector3d and complete
message bytes require exact equality; geometry tolerance does not prove wire
identity. No variance, covariance, pressure scaling or Earth/geodesy model is
introduced. Spherical coordinates and all existing unsupported inputs remain
refused, including atomic refusal of a late invalid owner.

The example [m52_multiple_magnetometers.sdf](../examples/m52_multiple_magnetometers.sdf)
has two distinct orientations, frames, rates and endpoints on one physical
body. The first owner is ideal; the second adds a deterministic X mean using the
existing Gaussian metadata. Its finite CLI run is the 26th example, after the
unchanged first 25. A two-step finite run proves loading and stepping only;
real force/torque, independent acquisition, noise, demand, reset and removal
require their separately observed controls.

Server admission validates the complete original identity/name/metadata set and
all resolved or remapped endpoints before publisher lookup, declaration or
reuse. Endpoint equality alone does not identify an owner after replacement.
The immutable initial query retains removed owners in the loader blueprint;
healthy reset preserves public IDs while replacing Bevy entity handles.
