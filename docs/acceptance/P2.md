# P2 acceptance: selected headless world

This record binds the selected first world to published implementation
[8d065a1](https://github.com/gazebosim-rs/gz-sim-rs/commit/8d065a1a3750d282bada085df4a29a8139a3e875).
Its mandatory normal hook and [exact hosted verification](https://github.com/gazebosim-rs/gz-sim-rs/actions/runs/40442119648)
passed. Independent review verifies this refreshed fifteen-row matrix and its exact
normal dependency receipt.

## Closure

On 2026-10-28 the owner closed P2 and SLICE-01 for this selected world. The PLAN.md
exit evidence is met on its stated scope: original and Rust runs agree on the
selected assertions, real C++ transport clients interoperate (seventeen
scenarios, plus the networked CLI executable on TPE and Rapier), queues are
bounded, and a first equal-work performance report exists. Closing the phase
does not complete the broader packets listed under "Quality, dependencies and
remaining work"; they keep their own exit criteria. In particular, the DART
adapter (PHY-03) is still required for same-engine parity and starts P3.

The [machine-readable matrix](../../planning/acceptance/p2.json) contains fifteen
contract rows with named passing witnesses, exact implementation source and
fixture hashes, consumer pins, backend qualifications and remaining scope.
The [original audit](../../planning/acceptance/history/d4c73ee/p2.json) and
[formal refusal](../../planning/acceptance/history/d4c73ee/p2-exit-review.json)
are preserved byte-for-byte. Historical relative links are interpreted at that
record's original published revision.

## Selected world and boundaries

The shared headless_imu.sdf uses a static box ground, a dynamic sphere, explicit
mass/inertia and gravity, a noise-free IMU, 1 ms steps and real-time factor zero.
A separate world-revolute pendulum fixture exercises the simple joint variant.
Rust constructs Bevy entities; role identities are stable opaque IDs, not copied
C++ ECM storage slots.

TPE supplies its declared motion/contact behavior. Full-f64 Rapier is the chosen
first dynamic backend. Native DART samples provide qualified cross-engine
physical checks; they do not certify a Rust DART adapter or same-engine DART
parity. That adapter remains a release requirement. Local/offline resources and
explicit capability errors define this selected construction boundary.

## Cadence and equal work

The previous unthrottled Rust pose-default blocker is obsolete. The accepted
server uses the native 60 wall-Hz admission ceiling of 16,666,667 ns, with
subscriber suppression before packet construction and timer advancement. Boundary
and actual integration witnesses are bound separately. This closes that specific
old gap, not the complete IO-01 contract or unqualified whole-server reset parity.

The measured common workload waits at least 20 ms after complete clock/pose/IMU
receipt before requesting the next 1 ms step. All three observations are required;
there are no extra steps, enlarged queues or hidden readiness sleeps. Actual
server-call, receive, decode and validation work is measured separately from
pacing and wall time. Simulated times, physical values, role identities and all
header/frame/sequence/covariance fields are checked. Opaque ID varint differences
alone receive the declared cross-run byte adjustment; raw sizes remain recorded.

The [current report](../../planning/benchmarks/headless-streams-imu-activation-v1.json)
retains two separate eleven-pair batches: one declared warmup and ten measured
pairs per batch. The paired Rust/native geometric work-latency ratios are 0.63209
and 0.64465, with separate bootstrap intervals and every extreme retained. These
are shared-host, default-active TPE stream observations, not activation-toggle,
causal, general, unpaced-throughput or balanced robotics results. Historical
measurements remain separate. Embedded preliminary metadata snapshots allow exact
reconstruction of the measured source tree despite later publication metadata.

## Quality, dependencies and remaining work

The accepted source and normal gates pass 279 Rust tests and 88 tooling tests.
Workspace production coverage is 3830/3870 lines and 5873/6004 regions. Every
production crate independently satisfies covered*100 > total*95 for both metrics;
changed scene/server executable lines are 22/22 and 7/7. Policies, assertions and
numerical tolerances are unchanged.

The [normal dependency receipt](../../planning/acceptance/p2-normal-dependencies.json)
binds the exact command, lock, package set and normalized stdout. It describes
normal Rust dependencies, separately from libraries loaded by native reference
binaries. The current immutable TPE SDK and qualified older DART/native captures
retain their different provenance; they are not interchangeable evidence.

Broader LOAD-01, PHY-02, the chosen dynamic backend,
SENSOR-01, IO-01 and P0 exits remain open where their full contracts are unmet.
The six proposed scope dispositions in the JSON matrix preserve these edges and
the earlier refusal; they do not silently turn subset evidence into packet
completion. DART/MuJoCo adapters, general articulation, rendered and other sensor
families, extension ABI, remaining systems and release qualification continue in
the wider plan.
