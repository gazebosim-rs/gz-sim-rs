## Selected world and implementations

The shared headless_imu.sdf contains static box ground, one dynamic spherical body,
explicit mass/inertia, gravity and one noise-free IMU at 1000 Hz. Physics uses 1 ms
steps and real-time factor zero. Rust constructs Bevy entities and components;
public identities are opaque world-local IDs, not copied C++ ECM storage slots.
The simple pendulum/world-revolute variant is a separate retained fixture.

TPE uses its native constant-motion/no-gravity-dynamics semantics. Full-f64 Rapier
is the selected first dynamic engine. Native DART controls provide declared
cross-engine physical checks; a Rust DART adapter and same-engine DART parity are
still required later. Ground is a finite box covering the selected workspace;
this record does not certify all geometry, contacts or articulations.

## Clock, byte and performance contract

Native SceneBroadcaster hardcodes pose/info to 60 wall-Hz. An unpaced attempt
failed with IMU=2, clock=2, pose=1 at the second step; the failure remains retained.
The common workload waits at least 20 ms after each completed three-stream
observation before requesting another single 1 ms step. Both must receive all
three observations before proceeding. There are no hidden extra steps, retries,
SDK patches, enlarged queues or sleeps treated as readiness.

The report sums actual server-call, receipt, decode and validation intervals;
pacing and total wall time are separate. Every simulated timestamp, body pose,
role identity, frame/sequence/covariance/header field and byte-accounting check
is enforced. Host clocks need valid/current domains and monotonic real time,
not equal values across processes. Opaque ID varint values alone are subtracted
for the cross-run pose size comparison, with exact length/accounting guards.
Raw sizes remain recorded. See [STREAM_OBSERVATIONS.md](../STREAM_OBSERVATIONS.md).

Seven alternating process pairs after a warmup pair each execute 128 measured
steps. The median of seven process-mean work latencies is native 77.438 us and
Rust 43.748 us; ranges are 73.459..127.151 us and 36.051..268.729 us. The large Rust
outlier is retained. This selected result is not unpaced throughput, an inverse
latency throughput estimate, a service guarantee or whole-Gazebo performance.
Independent full replay reproduced counts, field/byte checks and physical
checksums; its timings remain a separate run. Missing-stream/report mutants fail
as expected. Earlier unpaced IMU-only and within-Rust executor/pin experiments
retain their original scopes and raw data.
