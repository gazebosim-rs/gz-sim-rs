# Qualifying the GPU physics workloads on the RTX 5090

The physical GPU suite passed all 62 cases across 14 Rust test targets. It exercised resident contact, device failure and rollback, collisions, SDF loading, robot joint commands and sensor transport. The new process test compares three successive contact results with independent Vulkan lanes, including a rejected request between successful continuations and graceful exit after the last reply. [Results](gpu-hardware-qualification.json)

The renderer qualifier now runs those hardware cases when a physical adapter is explicitly selected through `GZ_GPU_ADAPTER`. It enumerates the ignored tests from the renderer build, checks each executable's identity before and after execution, and retains the device, case names, stdout and stderr. The machine must have its f64 Vulkan driver available.

On the frozen 84569c9 renderer build, the original aggregate exercised 39.37% of GPU physics regions. Running its 61 pre-existing cases on hardware and checking its real worker at graceful exit supplied 66 hardware profiles. All 66 matched ELF build IDs in the frozen build, across 16 executables. Merging into the existing renderer report covered 5,115/5,320 GPU lines and 8,447/8,867 GPU regions (96.15% and 95.26%). This aggregate retains LLVM's duplicate-function mismatch warning. An independent check exported profiles only against their individual matching executables, with no mismatch warnings, then took the union by source location. That check measured 4,906/5,066 lines and 8,480/8,867 regions across all 29 GPU source files. One original profile had no matching executable and was excluded from the independent check.

The shared simulator scene and CLI remain below their renderer coverage gates. The older combined build also had a headless fleet test failure, subsequently fixed. The hardware result qualifies the GPU crate on this frozen source and device. The integrated workspace release remains under test.

The stock server also ran a fresh 600-tick arm trace on the RTX 5090. All published numeric samples matched the earlier capture byte for byte. The elbow and shoulder motions stayed within 0.840 mm of the independent Rapier tool path. Both solvers hit the lower and upper shoulder stops at 211 and 510 ms. The first loaded tick delivered 0.29771 N·s on the GPU and 0.31638 N·s with the 16-substep native reference. gz-web-rs verified all 34 recorded frames and 170 displayed shapes or poses, including the final state.
