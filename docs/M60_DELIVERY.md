## Required fresh installed proof

After final Source qualification and source-bound assembly, one supported clean,
relocated installation must:

- Verify the complete package and copied resources, and execute the installed
  M58 and M59 finite fixtures through the actual installed simulator.
- Launch M59 using `run --example`, command both robot topics through the actual
  installed finite helper, and retain measured motion plus canonical encoder
  Odometry observations using maintained client code. Discovery alone is not
  command application, motor response or a wire epoch acknowledgment.
- Show both robots in the maintained live browser and demonstrate actual
  Play/Pause/Reset. Reusing unchanged viewer bytes does not replace this proof.
- Complete owned process/listener shutdown without touching an unrelated owner,
  and retain independent package/manifest/ELF/resource/installation evidence.

Two-step finite loading is separate from sensor acquisition/noise, command,
physical-response, lifecycle and wire evidence. There is no new original Gazebo
System campaign, provider rebuild, solver or trajectory-parity claim. Encoder
odometry is not commanded velocity times time or slip-free body ground truth.
