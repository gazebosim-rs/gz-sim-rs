## Closed prerequisite and seam decisions

M104 consumes valid already-resolved primitive inertia, whether entered explicitly
or produced by the pinned existing automatic primitive calculation. It adds no
automatic-inertia producer or provenance field. Its narrow `initial.rs` prerequisite
removes only the categorical captured nonzero-COM refusal; all live-versus-captured
optional Some/None/value checks, hierarchy, IDs and ownership remain exact. The
centered/tiny-COM route and the runtime-copy admission policies are preserved.
Translated inertial rotation is identity; it is not offset articulation support.

M105 and M111 have a single systems writer for Server `lib.rs`. Multi-robot
VelocityControl retains existing PostStep-latched commands and complete owner
preflight; it does not teleport bodies. The camera family is an explicit three/four
RGB constructor and CLI opt-in, preserving scalar/pair/depth/mixed constructors.

M106 changes only the existing moving-parent generalized-effort couple and its
complete accumulation preflight. Motors, servos, native solvers and joint types
stay within their existing domains. M107 computes primitive local AABBs and
unions before the existing LINK/model conservative envelope stages; TPE remains
kinematic, with bounded overlap reports rather than physical contact resolution.

M108 preserves exact legacy planar geometry and its positive-zero single-row
vertical packet fields. New rows are elevation-major/horizontal-minor with a
checked total no greater than 128 rays. The new C++ observer is one transport-only
leaf in the retained selected native-client framework: it validates a genuine
canonical spatial packet, not native sensor/physics parity. Root owns shared
registration and old constructor attachments; the planar observer stays exact.

M109 builds true spherical-cap meshes at the actual radius and segment length;
it never anisotropically stretches a fixed capsule. M110 shares the same writer
for renderer `gpu.rs`, uses tight actual curved support, and still refuses every
actual tangent/intersecting/behind-near input. Generic box validation stays exact.

M112 and dependent M113 share one Root DiffDrive lease. Limiters shape commands,
not actual body acceleration or ideal traction. Retained native order is jerk,
acceleration, then velocity; the discrete current-duration second difference has
no half coefficient. Defaults retain the old path. Complete owner/native target
preflight precedes history commit, and measured encoder odometry is unchanged.
