# Local mesh fixture

Original procedural glTF 2.0 pyramid, external vertex buffer and one white PNG
texel, licensed under Apache-2.0. Four flat shaded faces point along glTF +Y.
The embedded material supplies the green color. The SDF fixture applies a
nonuniform scale and rotated, offset visual so double axis conversions and
lost visual transforms are observable. Collision remains a Rapier box.
